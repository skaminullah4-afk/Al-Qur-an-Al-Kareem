# Al-Qur'an Al-Kareem
Black & gold Qur'an reader: Arabic (Uthmani), English (Sahih International) and Urdu (Kanz-ul-Iman).

- Browse **Surah-wise** (114) or **Parah-wise** (30)
- **Reading** mode: continuous Arabic text
- **Translation** mode: ayah by ayah with English / Urdu toggles
- Installable app (PWA). Tap **Download for offline use** once; after that everything works with no internet

## Deploy on GitHub Pages
1. Create a repo, add `index.html` and this README
2. Settings → Pages → Deploy from branch → `main` / root
3. Open `https://<username>.github.io/<repo>/`

## Install as an app
Open the GitHub Pages link on your phone → browser menu → **Add to Home Screen / Install app**. Then tap **Download for offline use** once.
